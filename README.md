# Elliptical Training Planner

A personal project for planning workouts on an elliptical trainer. The intended training load may take readiness and recovery metrics into account, while workout heart rate can be monitored with a Polar H10 chest strap.

## Current status

The GitHub Pages site is a project information page with a Privacy Policy and Terms of Use. Oura integration is not configured. The project does not access, receive, store, or transmit Oura metrics.

Any future Oura integration will be considered only after confirming an access method permitted by Oura, obtaining the account owner's consent, and updating the privacy information before data processing begins.
