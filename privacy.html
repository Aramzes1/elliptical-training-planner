Privacy Policy

Date: November 19, 2026

Elliptical Training Planner is a personal project for planning elliptical trainer workouts. As of this revision, Oura integration is not configured, and the project does not receive, store, or transmit ring metrics.

Website data

The pages are hosted on GitHub Pages. GitHub may process technical visit logs in accordance with its own privacy policy. This site does not accept Oura metrics.

Future integration

Access to Oura data will not be enabled until an Oura-permitted connection method is established and the account owner has given consent. Before any such feature is enabled, this policy will be updated to describe the data categories used, purpose, recipients, storage method, and how access can be revoked. Metrics will not be sent to an AI service based on this page or the current configuration.

Storage and access control

The project currently stores no Oura tokens or data. If an integration is added, the user will be able to revoke the permission granted through Oura integration settings. Applicable retention periods will be published before data processing is enabled.

Contact

This project is intended for its owner's personal use. For questions about the site, contact the owner through the repository owner's GitHub profile.
