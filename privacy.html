Elliptical Training Planner — личный проект для планирования тренировок на эллиптическом тренажёре. Он не является публичным сервисом и не предназначен для обработки данных других пользователей.

Какие данные используются

При подключении Oura приложение может получать только те категории данных, на которые пользователь дал разрешение в Oura, включая ежедневные сводки, тренировки, частоту сердечных сокращений, стресс, сессии, SpO₂, метки, конфигурацию кольца и показатели здоровья сердца. Адрес электронной почты и личные данные запрашиваются только если пользователь отдельно включит соответствующие разрешения.

Для чего используются данные

Показатели используются по запросу пользователя для составления и корректировки личного плана тренировок и для объяснения динамики нагрузки и восстановления. Данные не продаются и не используются для рекламы.

Передача и обработка

Данные запрашиваются через Oura API после OAuth-разрешения пользователя. Если пользователь передаёт показатели в ИИ-помощник для анализа, они обрабатываются сервисом ИИ в соответствии с его настройками и политиками хранения. GitHub Pages размещает только эти информационные страницы и не получает показатели кольца через это приложение.

Хранение и контроль доступа

Приложение не предоставляет отдельную облачную базу данных для хранения показателей. Данные и токены могут обрабатываться клиентом или локальным подключением, используемым пользователем; их техническое хранение зависит от выбранного клиента. Пользователь может отозвать доступ приложения в настройках интеграций Oura. После отзыва приложение не сможет получать новые данные.

Связь

Этот проект предназначен для личного использования его владельцем. Запросы по работе Oura API можно направлять в поддержку Oura; вопросы о размещённых здесь страницах — владельцу GitHub-репозитория, где размещён сайт.
